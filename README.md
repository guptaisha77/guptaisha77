## 🚀 Currently building

**`ask-my-docs`** — a domain-specific Q&A system over your own documents, built to go beyond the typical “embed and vector-search” RAG demo.

- **Hybrid retrieval** — BM25 keyword search fused with semantic vector search, so exact terms *and* meaning are covered
- **Cross-encoder reranking** (Cohere) to surface the genuinely relevant passages
- **Enforced citations** — every answer is validated back to its source passages, with a retry if any are missing
- **CI-gated evaluation** — RAGAS metrics run on every PR and block merges that regress answer quality
- Stack: **React + Vite**, **FastAPI**, **ChromaDB**, **Groq** (Llama 3.1), **LangGraph**, **GitHub Actions**
